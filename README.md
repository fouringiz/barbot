# Bar-bot — спеки, стоп-лист, заявки

Группа с топиками + Google Sheets. Без ролей.

## Команды

| Команда | Что делает |
|---|---|
| `/spec негрони` | карточка в мл; нечёткий поиск, латиница/кириллица, опечатки |
| `/have джин лайм` | что можно собрать из этих ингредиентов (стоп-лист учитывается) |
| `/menu` | авторская линия — спеки с тегом `меню` |
| `/stop` | текущий стоп-лист |
| `/stop + лайм` / `/stop - лайм` | поставить/снять → пост в топик «Стоп-лист» + какие коктейли падают |
| `/need нет горячей воды` | заявка; тип ставится сам: поломка / оборудование / расходник → пост в «Заявки» |
| `/needs` | открытые заявки, поломки сверху |
| `/done 14` | закрыть №14 — пост в топике зачёркивается |
| `/reload` | перечитать спеки из таблицы (иначе кэш 10 мин) |
| `/id` | id чата и топика — нужно один раз при настройке |

Авто: каждый день 11:00 — стоп-лист в «Стоп-лист»; понедельник 11:05 — заявки, висящие больше 3 дней, в «Заявки». Время — Баку.

## Запуск с нуля

### 1. Бот в Telegram (3 мин)
1. @BotFather → `/newbot` → имя → username (кончается на `bot`). Скопируй **токен**.
2. `/setprivacy` → выбери бота → **Disable** (чтобы видел команды в группе без лишних вопросов).

### 2. Группа с топиками (5 мин)
1. Создай группу → настройки → **Topics / Темы: вкл.**
2. Создай топики: **Стоп-лист**, **Заявки**. General остаётся для общения.
3. Добавь бота в группу, сделай **администратором** (достаточно права «отправлять сообщения» и «удалять/редактировать» свои).
4. Бота пока нет онлайн — пропусти шаг 5 и вернись сюда после первого запуска. Либо запусти локально (см. ниже) с временными значениями `GROUP_ID=1 TOPIC_STOP=0 TOPIC_NEEDS=0`.
5. Напиши `/id` в General → получишь `chat_id` (отрицательное число, начинается на -100). Напиши `/id` в топике «Стоп-лист» → `topic_id`. Повтори в «Заявки».

### 3. Google Sheets (10 мин)
1. console.cloud.google.com → новый проект → **APIs & Services → Library** → включи **Google Sheets API**.
2. **APIs & Services → Credentials → Create credentials → Service account** → любое имя → Done.
3. Открой созданный аккаунт → **Keys → Add key → JSON** → скачается файл. Это `GOOGLE_CREDS_JSON`. Запомни `client_email` из него (вида `xxx@yyy.iam.gserviceaccount.com`).
4. Создай Google-таблицу. Три листа с точными именами и заголовками в первой строке:

   **specs**
   `name | aliases | ingredients | method | glass | garnish | pitch | tags`
   - `aliases` — через запятую: `negroni, негрони классический`
   - `ingredients` — через `;`, мл в конце: `джин 30; кампари 30; сладкий вермут 30`
   - `tags` — через `;`; тег `меню` = авторская линия
   - Для старта: **Файл → Импорт → `specs_example.csv` → заменить текущий лист**

   **stoplist**
   `item | since | who | note` — бот заполняет сам

   **needs**
   `id | type | text | who | created | closed_by | closed_at | msg_id` — бот заполняет сам

5. **Поделиться** таблицей с `client_email` из шага 3, права **Редактор**.
6. `SHEET_ID` — из URL таблицы: `docs.google.com/spreadsheets/d/`**`ВОТ_ЭТО`**`/edit`.

### 4. Хостинг на Railway (10 мин)
1. Залей папку в приватный репозиторий GitHub (без `.env`!).
2. railway.app → **New Project → Deploy from GitHub repo** → выбери репо.
3. **Variables** → добавь шесть переменных из `.env.example`. `GOOGLE_CREDS_JSON` — весь JSON ключа **одной строкой** (открой файл, скопируй целиком, Railway сам справится с переносами).
4. **Settings → Deploy** — убедись, что команда старта `python bot.py` (подхватится из `Procfile`).
5. Deploy. В **Logs** должно быть `polling started`.

Без GitHub: `npm i -g @railway/cli` → `railway login` → в папке `railway init` → `railway up` → переменные через `railway variables set KEY=value`.

### Локально (для теста)
```bash
pip install -r requirements.txt
cp .env.example .env   # заполни
export $(grep -v '^#' .env | xargs)   # или set -a; source .env
python bot.py
```

## Как расширять
- Новый коктейль — строка в `specs`, потом `/reload`.
- Новые ключевые слова для типов заявок — `BREAK_KW` / `EQUIP_KW` в `bot.py`.
- Время рассылок — два `CronTrigger` в `main()`.
- Следующие модули по плану (батчи, чек-листы, передача смены) — каждый отдельный лист + 2–3 хендлера по тому же шаблону.
